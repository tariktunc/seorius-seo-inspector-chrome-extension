KurulumInstall

Durum: geliştirme aşamasında. Henüz Chrome Web Mağazası'nda yok.Status: in development. Not on the Chrome Web Store yet.

Gereken: Node.js 20 veya üstü (geliştirme Node 24 ile yapıldı).Requires Node.js 20 or newer (developed on Node 24).

git clone https://github.com/tariktunc/seorius-seo-inspector-chrome-extension.git
cd seorius-seo-inspector-chrome-extension
npm install
npm run build
  1. Chrome'da chrome://extensions sayfasını açın.Open chrome://extensions in Chrome.
  2. Sağ üstten Geliştirici modunu açın.Enable Developer mode (top right).
  3. Paketlenmemiş öğe yükleye basın ve dist/ klasörünü seçin.Click Load unpacked and choose the dist/ folder.
  4. Bir sayfa açın ve araç çubuğundaki Seorius simgesine tıklayın.Open any page and click the Seorius icon in the toolbar.

Google arama sonuçları katmanıGoogle SERP overlay

Google'da arama yaparken sonuç sayfasına bilgi ekler. Yalnızca açık olan sonuç sayfasını okur ve hiçbir ağ isteği yapmaz; Semrush, Whois veya başka bir üçüncü taraf verisi kullanılmaz.Adds information to Google result pages. It only reads the page that is open and makes no network requests; no Semrush, Whois or other third-party data is used.

  • Organik sonuçlara sıra numarası (2. sayfa 11'den başlar, aynı adres bir kez sayılır).Rank numbers on organic results (page 2 starts at 11; the same address is counted once).
  • Reklamlara ayrı renk, çerçeve ve "Reklam #n · üst/alt" etiketi. Organik sıraya karışmaz.Ads get their own colour, frame and an "Ad #n · top/bottom" label, and do not count towards organic rank.
  • SERP özellik etiketleri: öne çıkan snippet, "diğer kullanıcılar şunu sordu", yerel paket, video karuseli, görsel paketi, öne çıkan haberler, site bağlantıları, AI Overview.SERP feature tags: featured snippet, People Also Ask, local pack, video carousel, image pack, top stories, sitelinks, AI Overview.
  • Sağ altta açılıp kapanan panel: organik / reklam sayıları, açma-kapama düğmeleri, CSV indirme, AI Overview kaynak listesi + CSV, ülke / dil ile yeniden arama.A collapsible panel at the bottom right: organic / ad counts, toggles, CSV export, AI Overview sources + CSV, re-search by country / language.
  • Ayarlardan kendi alan adınızı girerseniz o sonuçlar ayrıca çerçevelenir.Add your own domain in settings and its results get an extra frame.

Katman yalnızca https://www.google.<ülke>/search* adreslerinde (43 Google alan adı) çalışır; başka hiçbir sitede çalışmaz.The overlay runs only on https://www.google.<country>/search* (43 Google domains) and nowhere else.

Tam raporFull report

Popup'taki "Tam raporu aç" ile ayrı bir sekmede açılır.Opens in its own tab from the popup.

  • Denetim: Teknik / İçerik / Mobil / Sosyal.Audit: Technical / Content / Mobile / Social.
  • Sayfa bilgisi, head öğeleri, başlık ağacı, görsel tablosu, bağlantı tablosu ve bağlantı kontrolü.Page info, head elements, heading tree, image table, link table and link checker.
  • Anahtar kelime yoğunluğu (1–4 kelime, Türkçe büyük/küçük harf duyarlı).Keyword density (1–4 words, Turkish-aware casing).
  • Open Graph / Twitter ve paylaşım kartı önizlemesi; JSON-LD / microdata / RDFa.Open Graph / Twitter and share-card preview; JSON-LD / microdata / RDFa.
  • Teknik bilgiler: durum, adım adım yönlendirme zinciri, başlıklar, HSTS, karışık içerik, HTML boyutu, robots.txt kararı, site haritası.Technical: status, step-by-step redirect chain, headers, HSTS, mixed content, HTML size, robots.txt decision, sitemap.
  • Ham ve işlenmiş HTML karşılaştırması, çerçeve ve izleme etiketi tespiti, 2–5 URL karşılaştırması.Raw vs rendered HTML comparison, framework and tracking-tag detection, 2–5 URL comparison.
  • Dışa aktarma: JSON / CSV / yazdır-PDF.Export: JSON / CSV / print-to-PDF.

Durum modeli: hata / uyarı / not / geçti / çalışmadı. "Çalışmadı" hiçbir zaman "geçti" sayılmaz. Uzunluk aralıkları öneridir, Google kuralı değildir.Status model: error / warning / note / pass / not run. "Not run" is never counted as "pass". Length ranges are suggestions, not Google rules.

Sayfada işaretlemeOn-page highlighting

Başlıkları, bağlantıları (nofollow, boş metin) ve alt metni olmayan görselleri sayfanın üstünde işaretler. İstek üzerine eklenir, kapatınca kaldırılır.Marks headings, links (nofollow, empty text) and images without alt text on the page itself. Added on request, removed when switched off.

AyarlarSettings

Dil (Türkçe / İngilizce), SERP katmanı (aç/kapat, numaralar, reklam işaretleme, özellik etiketleri, alan adım), işaretleme renkleri, ek etkisiz kelimeler ve beyaz liste, gösterilen denetim grupları, tablo sütunları, ayarları içe / dışa aktarma.Language (Turkish / English), SERP overlay (on/off, numbers, ad marking, feature tags, my domain), highlight colours, extra stop-words and allow-list, visible audit groups, table columns, settings import / export.

İsteğe bağlı izinOptional permission

Tam raporda "Yönlendirme zincirini göster", "Diğer sitelere erişime izin ver" veya "Başka sunuculardaki site haritalarını kontrol et" düğmesine bastığınızda Chrome bir kez izin ister. Tek izin üçünü de kapsar.When you press "Show redirect chain", "Allow access to other sites" or "Check sitemaps on other servers" in the full report, Chrome asks once. One permission covers all three.

  • webRequest dinleyicisi yalnızca eklentinin kendi isteği sürerken açıktır; gezinmenizi görmez ve kaydetmez.The webRequest listener is only active while the extension's own request runs; it does not see or record your browsing.
  • İzni vermezseniz eski davranış sürer ve ilgili satırda "çalışmadı" notu görünür.If you decline, the old behaviour continues and the row shows a "not run" note.
  • İzni chrome://extensions sayfasından geri alabilirsiniz.You can revoke it on chrome://extensions.

Gizlilik ve ağ istekleriPrivacy and network requests

  • Sayfa tarayıcınızda analiz edilir. Hiçbir sayfa verisi, URL veya geçmiş Blakfy sunucularına ya da üçüncü taraflara gönderilmez.Pages are analysed in your browser. No page data, URL or history is sent to Blakfy servers or third parties.
  • Tarama sırasında yalnızca incelenen siteye istek gider: sayfanın kendisi (ham HTML + yanıt başlıkları), robots.txt, aynı sitedeki site haritası.During a scan, requests go only to the inspected site: the page itself (raw HTML + response headers), robots.txt, and the sitemap on the same site.
  • Bağlantı kontrolü, görsel boyutu ölçümü, yönlendirme zinciri ve başka sunuculardaki site haritaları yalnızca siz başlatınca çalışır.Link checks, image-size measurement, the redirect chain and sitemaps on other servers run only when you start them.
  • Tüm istekler çerezsiz gönderilir.All requests are sent without cookies.

Sık sorulanlarFAQ

Satırda neden "çalışmadı" yazıyor?Why does a row say "not run"?

İlgili kontrol için gereken isteğe bağlı izin verilmemiş olabilir ya da siteye ulaşılamamış olabilir. "Çalışmadı" hiçbir zaman "geçti" sayılmaz; izni verip raporu yenileyin.The optional permission for that check may not be granted, or the site could not be reached. "Not run" never counts as "pass"; grant the permission and refresh the report.

İzni vermek zorunda mıyım?Do I have to grant it?

Hayır. İsteğe bağlı izin yalnızca yönlendirme zinciri ve başka sitelerdeki bağlantı / görsel / site haritası kontrolleri için gerekir. Diğer her şey izinsiz çalışır.No. The optional permission is only needed for the redirect chain and for link / image / sitemap checks on other sites. Everything else works without it.

SERP katmanı hangi sitelerde çalışır?Where does the SERP overlay run?

Yalnızca Google arama sonuç sayfalarında (www.google.<ülke>/search*, 43 alan adı). Başka hiçbir sitede içerik betiği çalışmaz.Only on Google result pages (www.google.<country>/search*, 43 domains). No content script runs anywhere else.

Chrome Web Mağazası'nda var mı?Is it on the Chrome Web Store?

Henüz yok; geliştirme aşamasında. Paketlenmemiş olarak yüklenir.Not yet; it is in development. Load it unpacked.
