Seorius

Açık sekmedeki sayfanın sayfa içi SEO'sunu tarayıcınızın içinde inceleyen, açık kaynaklı Chrome eklentisi. Veriniz tarayıcınızdan çıkmaz.An open-source Chrome extension that audits the on-page SEO of the current tab entirely inside your browser. Your data never leaves it.

Neler yaparWhat it does

Simgeye tıklayın, sayfanın SEO durumunu anında görün.Click the icon and see the page's SEO state instantly.

01

Açılır pencerePopup

URL, HTTP durumu, hata / uyarı / not sayıları ve altı sekme: Özet, Başlıklar, Görseller, Bağlantılar, Sosyal, Araçlar.URL, HTTP status, error / warning / note counts and six tabs: Overview, Headings, Images, Links, Social, Tools.

02

Google SERP katmanıGoogle SERP overlay

Organik sonuçlara sıra numarası, reklamlara ayrı etiket, SERP özellik etiketleri (öne çıkan snippet, AI Overview, yerel paket...) ve CSV indirme.Rank numbers on organic results, separate ad labels, SERP feature tags (featured snippet, AI Overview, local pack...) and CSV export.

03

Tam raporFull report

Teknik / İçerik / Mobil / Sosyal denetim, başlık ağacı, bağlantı kontrolü, anahtar kelime yoğunluğu, JSON-LD, robots.txt ve site haritası.Technical / content / mobile / social audit, heading tree, link checker, keyword density, JSON-LD, robots.txt and sitemap.

04

Yönlendirme zinciriRedirect chain

Sayfanın yönlendirmelerini adım adım, her URL ve durum koduyla gösterir (isteğe bağlı izinle).Shows the page's redirects step by step with every URL and status code (with an optional permission).

05

2–5 URL karşılaştırmaCompare 2–5 URLs

Birkaç sayfayı yan yana karşılaştırın; sonuçları JSON, CSV veya PDF olarak dışa aktarın.Compare several pages side by side and export results as JSON, CSV or PDF.

06

Sayfada işaretlemeOn-page highlighting

Başlıkları, nofollow bağlantıları ve alt metni olmayan görselleri sayfanın üstünde işaretler. İstek üzerine eklenir, kapatınca kalkar.Marks headings, nofollow links and images without alt text. Added on request, removed when you switch it off.

İlkelerPrinciples

SEO verisi hassastır; bu yüzden eklenti yerel çalışacak şekilde tasarlandı.SEO data is sensitive, so the extension is built to stay local.

•

Yalnızca yerelLocal only

Sayfa tarayıcınızda analiz edilir. Hiçbir sayfa verisi, URL veya geçmiş Blakfy'ye ya da üçüncü taraflara gönderilmez.Pages are analysed in your browser. No page data, URL or history is sent to Blakfy or any third party.

•

En az izinMinimal permissions

Kurulumda yalnızca activeTab, scripting, storage. host_permissions ve yoktur.Install-time permissions are only activeTab, scripting and storage. No host_permissions, no .

•

Tıklayınca çalışırRuns on click

Sayfa analizi yalnızca simgeye tıkladığınızda, yalnızca o sekmede çalışır.Page analysis runs only when you click the icon, and only in that tab.

•

Açık kaynakOpen source

MIT lisansı. Kodun tamamı repoda, ağ isteklerini doğrulayan bir denetim betiğiyle birlikte.MIT licence. All code is in the repo, with a check script that audits the network surface.

Hızlı kurulumQuick install

Henüz Chrome Web Mağazası'nda yok; paketlenmemiş olarak yüklenir.Not on the Chrome Web Store yet; load it unpacked.

git clone https://github.com/tariktunc/seorius-seo-inspector-chrome-extension.git
cd seorius-seo-inspector-chrome-extension
npm install
npm run build

Sonra chrome://extensions sayfasında Geliştirici modunu açıp Paketlenmemiş öğe yükle ile dist/ klasörünü seçin.Then open chrome://extensions, enable Developer mode and use Load unpacked on the dist/ folder.
